# 봉투 가계부 (envelope-budget)

달마다 돈을 봉투(분류)에 나눠 담는 한국어 가계부 웹앱. 휴대폰 화면 기준, 서버 없이 브라우저에만 저장한다.

## 기능

- **봉투식 예산**: 수입은 '배정할 돈'이 되고, 봉투마다 배정한다. 남은 돈은 다음 달로 넘어가고, 초과한 봉투는 빨갛게 보인다. 초과액은 봉투마다 '다음 달 이 봉투로 넘기기'(빚으로 이월) 또는 '다음 달 배정할 돈에서 빼기' 가운데 고른다. 봉투 사이 옮기기, 초과 메우기, 다음 달로 미루기, 지난달 복사, 3개월 평균 배정.
- **계좌와 거래**: 통장·카드·현금 계좌, 시작 잔액, 지출·수입·계좌 옮기기, 찾기, 미분류 모아 보기.
- **반복 거래**: 매일·매주·매월·매년(n마다), 횟수·날짜로 끝내기, 주말이면 금요일/월요일로, 날짜가 되면 자동으로 넣기, 놓침·오늘·곧 표시, 다가올 30일.
- **자동 분류 규칙**: 가게 이름이 같음·로 시작·을 포함 → 분류, 이름 바꾸기, 금액 범위. 구체적인 규칙이 이긴다. 같은 가게를 최근 5번 중 3번 같은 분류로 고르면 규칙을 배운다.
- **월 보고**: 수입·지출·남김, 분류별 지출(비율, 배정 넘김 표시), 묶음별, 최근 6달.
- **CSV**: 은행·카드사 CSV 가져오기(UTF-8·EUC-KR·UTF-16, 열 고르기, 출금/입금 열, 카드식 양수 지출, 겹친 거래 건너뛰기, 규칙 적용), 거래 CSV 내보내기(엑셀 수식 막기), JSON 백업·되살리기.
- 금액은 원화 정수. `12,000`, `1.2만`, `3만 2천`처럼 넣을 수 있다.

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm test         # node --test
npm run build    # dist/
```
